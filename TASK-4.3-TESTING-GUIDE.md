## Manual Testing Workflow

### Test 1: My Account Page Display

**Prerequisites:**
- WordPress + WooCommerce installed
- Speedy/Econt plugin active with credentials configured
- At least one completed order with a generated label

**Steps:**
1. Log in as a customer who has an order
2. Navigate to **My Account → Orders**
3. Click **View** on an order with a generated label
4. Scroll down past the order table

**Expected Results:**
- ✅ "Shipment Tracking" section appears after order table
- ✅ Carrier logo displays (or carrier name if logo missing)
- ✅ Tracking number is large and prominent
- ✅ Copy button appears next to tracking number
- ✅ "Current Status" badge shows if tracking data available
- ✅ "Track Your Shipment" button is visible
- ✅ Tracking timeline displays if events available
- ✅ "Refresh Tracking" button appears at bottom

**Actions to Test:**
- Click **Copy** button → Tracking number copied to clipboard
- Click **Track Your Shipment** → Opens carrier website in new tab
- Click **Refresh Tracking** → Page reloads with updated tracking info

## Common Issues & Solutions

### Issue: Tracking section not appearing
**Solution:**
- Verify order has a label (`wp_sesh_labels` table)
- Check label status is not 'pending' or 'cancelled'
- Verify user is logged in and has permission to view order

### Issue: Copy button not working
**Solution:**
- Check browser supports `document.execCommand('copy')`
- Try using Clipboard API for modern browsers
- Verify JavaScript loaded (`sesh-customer-tracking.js`)

### Issue: AJAX refresh fails
**Solution:**
- Check nonce is valid
- Verify user permissions
- Check API credentials configured
- Review `debug.log` for errors

### Issue: Email tracking not showing
**Solution:**
- Verify order has label before email sent
- Check email type is 'processing' or 'completed'
- Test email preview in admin
- Verify template files exist
