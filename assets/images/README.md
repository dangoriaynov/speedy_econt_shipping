# Carrier Logos

This directory should contain carrier logos for display in tracking information.

## Required Files

- `speedy-logo.png` - Speedy carrier logo (recommended size: 150x60px)
- `econt-logo.png` - Econt carrier logo (recommended size: 150x60px)

## Usage

These logos are displayed in:
- Customer tracking information on My Account pages
- Order confirmation emails (when using HTML email templates)

## Notes

If logo files are missing, the carrier name will be displayed as text instead.
Logos should be optimized for web use and support transparent backgrounds.
